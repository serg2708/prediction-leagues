Управление
Admin panel /admin — UI для синка матчей и записи результатов (вместо curl)

Пользовательский опыт
Discover tab — список публичных лиг которые можно найти и вступить
Profile page — статистика игрока, история предсказаний, процент побед
Share — кнопка "Поделиться" с deep link на лигу (для Farcaster)

Геймплей
Live updates — авто-обновление когда матч идёт в прямом эфире
Leaderboard — глобальный рейтинг по всем лигам
История предсказаний — что угадал/не угадал по завершённым матчам

Инфраструктура
Auto-sync cron — автоматический синк матчей каждый день
Webhook для результатов — автоматическая запись результатов через football-data.org

Деплой (приоритет)
Vercel — npx vercel → получишь публичный URL
Обновить NEXT_PUBLIC_URL в env на реальный домен
Добавить все env переменные в Vercel Dashboard

Для полного цикла (нужны ключи)
POOL_SIGNER_PRIVATE_KEY — без него on-chain payout не работает (победитель не получит USDC)
ADMIN_SECRET поменять с change_me_admin на случайную строку

Регистрация в Farcaster/Base App
Зарегистрировать Mini App в Warpcast Developer Portal
Добавить /.well-known/farcaster.json манифест
Протестировать в реальном Base App на телефоне

Что ещё можно добавить
Push уведомления когда матч начинается (сейчас только при результате)
Публичные лиги vs приватные (флаг is_public в БД)
Минимальное кол-во игроков перед стартом лиги
